## 다시 고칠 때
1. Claude 나 Codex 앱에서 이 폴더를 열고 고쳐 달라고 말합니다.
2. 아래 명령으로 GitHub 에 올리면, Vercel 이 알아서 사이트를 다시 배포합니다.

```bash
git add -A && git commit -m "수정" && git push
```
